We exclude patients with grayscale-equivalent channels while retaining the manifest, file hashes, and group identifiers.Data Partitioning and Leakage ControlThe dataset is partitioned at the patient level: slices with the same group_id never span the training, validation, and test sets. All models and random seeds use the same manifest, isolating adjacent slices and patient-specific characteristics across subsets and preventing them from biasing model comparisons.Image and Mask PreprocessingAll images are resized to 256 x 256 pixels and normalized with mean = 0.5 and standard deviation = 0.5. For light augmentation, a random horizontal flip with probability 0.5 and a rotation of up to +/-5 degrees are applied synchronously to each training image and its mask. Masks are binarized at a threshold of 128. The single-channel configuration reads the green channel of the original RGB image as FLAIR, whereas the three-channel configuration directly uses all RGB channels. Empty-mask balancing is enabled during training, with the positive-mask sampling ratio set to 0.40.Model ArchitectureWe compare a standard U-Net with ResNet34-U-Net. The latter replaces the conventional convolutional encoder with ResNet34 to construct a multiscale feature pyramid, after which the decoder restores the spatial resolution. Both networks output a single-channel lesion probability map and accept either single-channel FLAIR or three-channel input. We optimize with AdamW using an initial learning rate of 3 x 10^-4 and a weight decay of 1 x 10^-4. Training runs for at most 150 epochs; the learning rate is reduced when the validation metric plateaus, early stopping uses a patience of 30 epochs, and gradients are clipped to a maximum norm of 1.0. Automatic mixed precision is enabled when CUDA is available, and deterministic execution is enforced. For each random seed, the best checkpoint is selected solely by validation Positive Macro IoU and then frozen for test evaluation. Predictions are binarized at a threshold of 0.5. Experiments are implemented in PyTorch and run on a single NVIDIA GeForce RTX 5060 Laptop GPU with CUDA 12.8 and mixed precision.Evaluation MetricsThe primary metrics are Positive Macro IoU and Dice, which are widely used in medical image segmentation. Precision, Recall, Micro IoU, and the empty-slice false-positive rate provide complementary evaluation, following definitions used in related studies [4][9][10]. Positive Macro metrics assign equal weight to slices whose ground-truth masks contain lesions, emphasizing overlap quality on positive slices. The empty-slice false-positive rate monitors spurious activation on background-only slices.
